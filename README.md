# 目语心声 · 阿尔茨海默症老人智能辅具

> 用眼睛说话，让爱被听见。

一套面向阿尔茨海默症（AD）老人居家照护场景的一体化智能辅具开源实现，由**下位机智能辅具设备**与**上位机多端应用**组成。核心交互为「目语心声」模式：屏幕以左右双图呈现选项，老人**注视目标图片**即可完成需求表达，把"说不出口的话"翻译成家属能读懂的信号。

本仓库为下位机（嵌入式）部分：

- **K230** 视觉识别（人脸、摔倒、人形、人眼朝向）与视频流上传
- **兆易创新 GD32H759I-EVAL** 主控（云台人脸跟踪、药盒检测、设备翻倒检测、多模块串口调度）
- **ESP8266** MQTT 网关（数据上报与控制指令转发）
- **天问 ASRPRO** 语音播报

> 主控已完成从 Arduino Mega 2560 到 **GD32H759I-EVAL（ARM Cortex-M7，主频最高 600MHz）** 的更换，主控固件见 [`gd32h759i_eval/`](gd32h759i_eval/README.md)。

## 一、功能特性

### 1. 目语心声交互（核心）
- 屏幕提供「情绪 / 需求 / 行为」三类选项，每类以左右两张图片呈现
- 双通道输入：**人眼朝向识别**（注视左/右图即选择）＋ **触屏**兜底
- 选择结果由语音模块实时播报，实现"眼睛即语言"

### 2. AI 视觉识别（K230）
- 人脸识别：辨认老人与家属身份，支持到访提醒
- 摔倒检测：识别跌倒等异常姿态并触发告警
- 人形检测：判断老人是否离开画面，实现防走失提醒
- 人眼朝向识别：支撑目语心声交互
- 人脸自动搜索与锁定跟踪：持续对准目标人脸

### 3. 安全监护
- 设备翻倒检测（MPU6050）
- GPS 定位与位置上报（ATGM3365）
- 智能起夜灯：光敏传感器判断天黑 ＋ 视觉识别到老人，双条件自动点亮（直连 K230）

### 4. 生活辅助与情感陪伴
- 智能感应药盒：红外对射模块感应药盒开合状态
- 音频播放：DFPlayer Mini 屏幕点歌
- 语音播报：天问 ASRPRO 2.0
- AI 语音陪伴：ESP32-S3「小智」智能体（独立子系统，麦克风 INMP441 + 功放 MAX98357）

### 5. 远程守护
- K230 经板载 WiFi 以 **TCP 直传**实时画面至后端
- ESP8266 以 **MQTT** 上报摔倒、人形、目语心声选择、设备翻倒、GPS、药盒等状态
- 上位机（UniApp 三端：小程序 / 网页 / App）展示数据并推送告警

| 模块 | 选型 | 接口 | 说明 |
|---|---|---|---|
| 主控 | **兆易创新 GD32H759I-EVAL**（GD32H759，ARM Cortex-M7，主频最高 600MHz） | 多路 USART / I2C / SPI / GPIO / TIMER | 多外设调度、人脸位差计算、云台与屏控制 |
| 视觉 | 幻尔 K230 视觉开发板（CanMV / MicroPython） | UART ＋ 板载 WiFi | 全部视觉识别与视频流上传 |

| 云台 | 42 步进电机 ATK-S42H40D20 ＋ 驱动器 ATK-2MD5050 | 脉冲 / 方向 / 使能 | 一维云台人脸跟踪 |
| 姿态 | MPU6050 | I2C | 设备翻倒检测 |
| 定位 | ATGM3365 GPS | UART | 定位上报 |
| 光线 / 照明 | 光敏传感器 ＋ 起夜灯 LED | 直连 K230（ADC / GPIO） | 天黑且识别到老人时点灯 |
| 药盒 | 红外对射模块 | GPIO | 开合状态感应 |
| 联网 | ESP8266 | UART ＋ WiFi | MQTT 消息上报 |
| 语音陪伴 | ESP32-S3（小智固件）＋ INMP441 ＋ MAX98357 | I2S / WiFi | AI 语音对话（独立运行） |
| 音频 | DFPlayer Mini | UART | 点歌与提示音 |

## 四、快速开始

### 1. GD32H759I-EVAL 主控（Keil MDK / IAR）
1. 新建 GD32H759 工程，导入 GD32H7xx 固件库，将 `gd32h759i_eval/main.c` 与 `bsp/` 下文件加入工程；
2. 按 `gd32h759i_eval/README.md` 的引脚映射表配置串口、I2C 与步进电机引脚；
3. 串口分配：USART0→K230（115200）、USART1→ESP8266（115200）、USART2→串口屏（115200）、UART3→GPS（9600）、UART4→DFPlayer（9600）、USART5→天问（115200）；
4. 步进电机：脉冲/方向/使能接驱动器 PUL/DIR/ENA，驱动器与电机按 32 细分接线（一圈 6400 脉冲）；
5. 编译下载后，上电即进入人脸跟踪与传感器上报流程。

### 2. K230（CanMV IDE）
1. 用 CanMV IDE 打开 `k230/main_k230.py`；
2. 修改文件顶部的 WiFi 与服务器配置（见第五节）；
3. UART1（115200）接 ESP8266，UART2（115200）接 GD32 主控；
4. 光敏传感器与起夜灯 LED 按代码中的 GPIO 定义接线。

### 3. ESP8266（Arduino IDE）
1. 安装 ESP8266 开发板支持，以及库：`PubSubClient`、`ArduinoJson`、`Adafruit MPU6050`、`Adafruit Unified Sensor`；
2. 修改顶部 WiFi 与 MQTT Broker 配置；
3. 引脚：D2/D1 接 K230，D3/D4 接 GD32 主控，D5/D6 接天问模块（软串口）。

### 4. 天问模块
用天问Block 打开 `tianwen/天问.hd`，烧录后即可接收播报指令。

## 五、配置说明（重要）

仓库中所有凭据均已替换为占位符，**请填入你自己的配置**：

| 占位符 | 位置 | 含义 |
|---|---|---|
| `YOUR_WIFI_SSID` | K230 / ESP8266 | WiFi 名称 |
| `YOUR_WIFI_PASSWORD` | K230 / ESP8266 | WiFi 密码 |
| `YOUR_SERVER_IP` | K230 | 视频流接收服务器 IP（默认端口 9002） |
| `YOUR_MQTT_BROKER_IP` | ESP8266 | MQTT Broker 地址（默认端口 1883） |

> ⚠️ **请勿把真实的 WiFi 密码、服务器地址、MQTT 凭据提交到公开仓库。**

## 六、通信协议

### 1. MQTT 主题（示例，前缀按设备号调整）
| 主题 | 方向 | 说明 |
|---|---|---|
| `device/elder_2/fall` | 设备 → 后端 | 老人摔倒告警 |
| `device/elder_2/presence` | 设备 → 后端 | 人形检测 / 防走失 |
| `device/elder_2/gaze_cmd` | 设备 → 后端 | 目语心声选择结果（happy / hungry / wc / accompany 等） |
| `device/elder_2/mpu6050_flag` | 设备 → 后端 | 设备翻倒状态 |
| `device/elder_2/gps` | 设备 → 后端 | 经纬度等定位信息（JSON） |
| `device/elder_2/medicine_box` | 设备 → 后端 | 药盒开合状态 |
| `device/elder_2/call` | 设备 → 后端 | 一键呼叫 |
| `device/elder_2/camera_follow/control` | 后端 → 设备 | 云台自动搜索开关（`start` / `stop`） |

### 2. 串口链路
- K230 → GD32 主控（USART0，115200）：`F,<cx>,<cy>,<fw>,<fh>` 人脸；`FALL,1` 摔倒；`GAZE,L/R` 注视方向
- GD32 主控 → ESP8266（USART1）：`IR,0/1` 药盒；`TILT,0/1` 设备翻倒；`SEARCH,on/off` 搜索状态
- ESP8266 → GD32 主控：`start` / `stop` 云台自动搜索开关
- ESP8266 → 天问模块：播报文本
- 视频流：K230 经板载 WiFi 以 **TCP** 推送 JPEG 帧至后端（不经 ESP8266）
