# GD32H759I-EVAL 主控固件（云台跟踪 + 药盒检测）

本目录为「目语心声」下位机主控的 **兆易创新 GD32H759I-EVAL** 固件版本，替代早期的 Arduino Mega 2560 方案。

## 一、芯片与开发环境

| 项目 | 说明 |
|---|---|
| 主控芯片 | GD32H759 系列（ARM Cortex-M7，主频最高 600MHz） |
| 评估板 | GD32H759I-EVAL（板载调试器、按键、LED、TFT-LCD 接口、以太网、CAN-FD 等） |
| 开发环境 | Keil MDK 5（或 IAR EWARM）+ **GD32H7xx 固件库** |
| 调试方式 | 板载调试器（SWD/JTAG） |
| 逻辑电平 | 3.3V（与外设连接时需注意电平匹配，且必须与各模块共地） |

> 提示：GD32 各系列固件库 API 命名基本一致，但 **GD32H7xx 固件库的个别外设初始化参数与 H7 系列的时钟/引脚复用表** 与旧系列略有差异，编译前请对照你所用固件库版本与《GD32H759xx 用户手册》核对 `RCU`、`GPIO AF` 与 `TIMER` 配置。

## 二、引脚与接口映射

| 功能 | 外设 | 方向 | 连接对象 |
|---|---|---|---|
| 视觉通信 | USART0（115200） | 双向 | K230 视觉模块（人脸坐标、识别结果） |
| 联网通信 | USART1（115200） | 双向 | ESP8266（MQTT 上行 / `start`、`stop` 控制） |
| 人机交互屏 | USART2（115200） | 双向 | 淘晶驰串口屏（目语心声双图与触屏） |
| 定位 | USART3（9600） | 输入 | ATGM3365 GPS 模块 |
| 音频播放 | USART4（9600） | 输出 | DFPlayer Mini |
| 语音播报 | USART5（115200） | 输出 | 天问 ASRPRO 2.0 |
| 姿态检测 | I2C0（400kHz） | 双向 | MPU6050 |
| 药盒检测 | GPIO 输入 | 输入 | 红外对射模块 |
| 状态指示 | GPIO 输出 | 输出 | 板载 LED |
| 云台脉冲 | GPIO + TIMER | 输出 | 步进电机驱动器 PUL |
| 云台方向 | GPIO 输出 | 输出 | 步进电机驱动器 DIR |
| 驱动器使能 | GPIO 输出 | 输出 | 步进电机驱动器 ENA |

具体引脚号在 `bsp/bsp_*.h` 中以宏定义给出，可按实际布线修改。

## 三、代码结构

```
gd32h759i_eval/
├─ main.c                      # 主程序：初始化 + 主循环 + 协议解析 + 位差控制
├─ bsp/
│   ├─ bsp_uart.c/.h           # 多路 USART 初始化、接收环形缓冲、按行取帧
│   ├─ bsp_stepmotor.c/.h      # 步进电机脉冲输出（TIMER 中断）+ 方向/使能控制
│   ├─ bsp_gpio.c/.h           # 红外对射（带防抖）、LED 状态指示
│   └─ bsp_i2c_mpu6050.c/.h    # MPU6050 初始化与姿态读取（翻倒检测）
```

## 四、控制逻辑（与 Arduino 版本一致）

1. **人脸跟踪**：K230 经 USART0 上报人脸框中心坐标 `F,<cx>,<cy>,<fw>,<fh>`；主控计算其与画面中心（默认 320）的偏差 `off = cx - center_x`。
2. **死区判断**：`|off| > DEAD_ZONE(15px)` 时才动作，避免抖动。
3. **位差转脉冲**：`steps = |off| * STEPS_PER_PIXEL`，按偏差正负设定 DIR，交步进电机模块按加速曲线输出脉冲。
4. **丢失自动搜索**：超过 10s 未收到人脸帧则进入搜索模式，云台以固定步幅左右往复扫描；收到人脸帧即退出搜索。
5. **远程开关**：ESP8266 收到 MQTT 下发 `start` / `stop` 后转发给主控，控制自动搜索总开关。
6. **药盒检测**：红外对射 GPIO 变化（20ms 防抖）后上报药盒开合状态至 ESP8266。

## 五、与 K230 / ESP8266 的协议约定

- K230 → 主控（USART0，文本行）：`F,<cx>,<cy>,<fw>,<fh>`（人脸）；`FALL,1`（摔倒）；`GAZE,L/R`（目语心声注视方向）
- 主控 → ESP8266（USART1，文本行）：`IR,0/1`（药盒）；`SEARCH,on/off`（搜索状态）
- ESP8266 → 主控（USART1，文本行）：`start` / `stop`

> 以上帧格式需与 `k230/main_k230.py` 的实际输出保持一致，若 K230 端字段不同，请同步修改 `main.c` 中的 `parse_line()`。
